## 5. How comments are processed

1. Each comment is added to the log in section 1 with the date it was received.
2. A YouTrack task is created for each comment that needs a change; the task ID is written in the "Where addressed" column.
3. The change is made in a branch and pull request referencing that task; the PR link is added to the log.
4. The status changes to "Addressed" after the PR is merged, or to "Discussed, not changed" with the reason.
